# MDBPE_Medical
Code for the MSc thesis “Multidimensional Byte Pair Encoding for 2D, 3D and 4D Medical Image Classification” (Ontario Tech University, 2026)

This repository applies Multidimensional Byte Pair Encoding (MDBPE) to medical
images of increasing dimensionality and evaluates classification performance,
efficiency (sequence length, memory, inference time) and attention-rollout
interpretability against an uncompressed baseline.

| Folder   | Dataset       | Dimensionality |
|----------|---------------|----------------|
| `2d`     | BreastMNIST   | 2D grayscale   |
| `2d_rgb` | DermaMNIST    | 2D RGB         |
| `3d`     | OrganMNIST3D  | 3D (28×28×28)  |
| `4d`     | ACDC          | 4D cardiac MRI (32×27×2×8) |

Each folder contains the MDBPE processor(s), ViT-style
classifier, analysis scripts (ROC, inference time, attention rollout,
rescue/failure cases) and SLURM job scripts.

## Data
- BreastMNIST, DermaMNIST, OrganMNIST3D are downloaded automatically via the `medmnist` package.
- ACDC must be obtained separately from the ACDC challenge after registration.
  If you use it, cite: Bernard et al., "Deep Learning Techniques for Automatic MRI
  Cardiac Multi-Structures Segmentation and Diagnosis", IEEE TMI, 2018.

No data, tokenized sequences or model checkpoints are included; they are
regenerated by running the scripts.

## Setup
Experiments were run on the Nibi cluster (Digital Research Alliance of Canada),
NVIDIA H100 GPUs, Python 3.11.

    python -m venv mdbpe_env
    source mdbpe_env/bin/activate
    pip install -r requirements.txt

Data and output paths are set at the top of each script and must be adapted.

## Running
For each dataset: processor → classifier → analysis scripts.
Exact commands for every table and figure in the thesis are in `docs/reproduce.md`.
